# Slices (V3)

Concrete task slices are authored just-in-time under
`slices/[phase]/[slice-name].md` when a phase opens. The phase docs list the
planned slice names and scopes; the archived v2 slices
(`docs/archive/audit-stability-and-performance-v2/phases/slices/`) are the
structural template (scope, anchors, target shape, invariants, done criteria,
validation).
