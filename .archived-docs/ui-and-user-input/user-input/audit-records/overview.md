# User Input Persistence And Stale-State Audit Overview

This file consolidates three historical views of the same input surface. Read them in order: the baseline inventory maps the persistence path, the verification audit corrects or qualifies that baseline, and the stale-state assessment supplies the final risk lens. When verdicts differ, the later section supersedes the earlier one.

## Baseline Persistence Inventory

This directory documents client buttons and text fields that can change persisted app data in the Fastify client. It groups controls by UI surface and links each surface to the client mutation helper and server handler that writes the database.

Scope notes:

- "Database" means the Fastify-backed app state and asset store: command events, SQLite/projected rows, `data/assets`, and server-owned import/backup/memory job tables.
- Text fields include native `<input>`/`<textarea>` plus wrapper components such as `TextInput`, `TextAreaInput`, `SettingText`, and `SettingTextarea`.
- Buttons include native `<button>` plus wrapper components such as `Button`, `BaseRoundedButton`, and popup/menu items that directly invoke a persistent action.
- Controls that only search/filter, open/close panels, export/download, mutate local translator cache, or write a remote Realm database are excluded or called out as non-local persistence.
- Some editors persist by changing a bound draft. In those cases the unique id is the draft key or bound field path rather than a DOM selector.

## Stale-State Assessment

Audit method: manager synthesis of validation-agent review over `.archived-docs/ui-and-user-input/user-input/audit-records/overview.md`, with local spot checks of command transport, projection reconciliation, settings rollback, and character draft rollback.

Verdicts:

- `Pass`: stale async overwrite protection appears adequate for this row.
- `Risk`: plausible stale overwrite path, usually on failure, rollback, or destructive resync paths.
- `Issue`: normal delayed async completion can overwrite newer user/local state.
- `N/A`: row has no relevant persisted local async state boundary.

### Pattern Keys

| Key                  | Meaning                                                                                      |
| -------------------- | -------------------------------------------------------------------------------------------- |
| `Cmd`                | Command uses `baseRevision` and active-writer headers; server rejects stale revisions.       |
| `AttemptRollback`    | Rollback only restores when the live value still equals the failed attempted value.          |
| `BroadRollback`      | Rollback restores a whole snapshot or collection and can clobber newer edits.                |
| `ProjectionDirtyGap` | Successful projection/reseed can replace a local draft that changed after the request began. |
| `UploadNoToken`      | File/upload/import callback resumes without a request id, entity id, or dirty-state guard.   |
| `FullResync`         | Import/restore/full bootstrap applies a whole projection and can replace newer local state.  |
